# SAI Group International – Sitio web corporativo

Sitio estático de una sola página (`index.html`), sin dependencias de compilación.
Logos y fotografías van incrustados en el archivo.

## Formulario de contacto
En `index.html`, dentro del `<script>`, complete:
- `FORM_ENDPOINT`: URL del servicio que recibirá los mensajes.
- `CONTACT`: correo, teléfono y dirección que desee mostrar.
